# Neat Framework CLI Demo

Showcases the revolutionary CLI capabilities of Neat Framework!

This demo demonstrates:
- Project generation (`neat new`)
- Code generation (`neat generate`)
- Development server (`neat dev`)
- Auto-discovery analysis (`neat scan`)
- Project health checks (`neat doctor`)
- Information display (`neat info`)

The Neat CLI makes development incredibly productive!
