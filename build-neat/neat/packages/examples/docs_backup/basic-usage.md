# Neat Framework - Basic Usage Example

This example demonstrates the fundamental usage of the Neat framework with the @StartupApplication decorator and basic controllers.

Key Features Demonstrated:
- @StartupApplication decorator for zero-configuration startup
- @Controller decorator for HTTP route grouping
- @Get, @Post decorators for route definitions
- Automatic dependency injection
- Type-safe request/response handling
- Graceful shutdown handling

NOTE: This example shows the intended API usage. The actual decorators and framework implementation will be built in subsequent steps.
